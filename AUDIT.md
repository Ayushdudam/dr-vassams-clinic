## 2. Accessibility & Usability Standards Compliance
- **WCAG 2.1 Level AA**: All interactive touch targets exceed 44×44px minimum (`min-h-[44px]`). Contrast ratios exceed 4.5:1 for normal text and 3:1 for large text.
- **Form Usability**: Client-side validation with `zod` schema, accessible error summary with programmatic focus management, and honest server status handling.
- **Responsive Viewport Stability**: Zero horizontal layout overflow across all standardized viewports (360px, 375px, 390px, 412px, 768px, 1024px, 1280px, 1440px).
